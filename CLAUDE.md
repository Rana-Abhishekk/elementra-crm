## Elementra CRM — project facts

- **Ports:** app 4610 (`npm run dev`), Postgres 5610 (Docker, `npm run db:up`), Prisma Studio 5611. Never use 3000 or 5432.
- **Commands:** `db:up` → `db:migrate` → `db:seed` → `db:seed:demo` → `dev:all` (app + local reminder runner). Checks: `demo:check` (11 scenarios), `demo:acceptance` (§19 server paths; resets demo data). Gates before every commit: `npm run lint`, `npm run typecheck`, `npm test` (+ `npm run build` before hand-off).
- **Folders:** `app/dashboard/**` (pages + `actions.ts` server actions), `app/api/**` (webhooks, public, cron, polling), `lib/prisma.ts` (client), `lib/auth/` (NextAuth options; `getCurrentUser()` per request; `scope.ts` = the ONLY visibility rules (`leadWhere`/`userWhere`); `guards.ts` = `can()`/`requirePermission()`; `permissions.ts` catalogue; `escalation.ts`), `lib/data/masters.ts` + `lib/domain/stages.ts` (stages/sources/products/pipelines come from the DB), `app/dashboard/masters/**` (admin screens), `lib/domain/**` (pure business logic, unit-tested with Vitest), `lib/features.ts` (feature-status registry → badges, Build Status page, `STATUS.md`), `prisma/` (schema, migrations, seeds).
- **Rules:** all data synthetic (`+9190000xxxxx`, `@example.com`, `@elementra.test`); no real Meta/WhatsApp/Google calls (simulators by default); store UTC, show IST; every automatic decision writes a timeline entry.
- **Access rules:** JWT holds only the user id. Every server action / route handler calls `requirePermission()` (or a helper that does) and filters with `leadWhere()`/`userWhere()`; `lib/auth/coverage.test.ts` fails if one doesn't. Out-of-scope leads → `notFound()`.
- **No business labels in code:** use stage `category` (OPEN/WON/LOST), flags (`isInitial`, `askReviveDate`, `requiresQualification`, `staleDays`) or `systemKey` hooks, never labels. Seeds/demo generator are the only places that name seeded rows (`lib/domain/masters/defaults.ts`).
- **Phone = customer key:** `Contact.phoneE164` unique; `Lead.openPhoneKey` (= phone while open) unique → one open lead per number. Keep `openPhoneKey` in sync on every stage/phone change (`openPhoneKey()` in `stages.ts`).
- **Roles:** Super Admin (locked, replaces Owner/Admin), Branch Manager, Sales Executive, Online Desk, Management Viewer. Demo logins: password `Demo@1234`; Vikram Sethi = regional manager (Worli + Andheri + Tardeo).
- **Docs:** spec `project_docs/01_PRODUCT_AND_DEMO_SPEC.md`, data `project_docs/02_REFERENCE_DATA.md`, plan & decisions `project_docs/IMPLEMENTATION_PLAN.md`, status `STATUS.md`, staging `STAGING.md`, Week 2 spec `project_docs/06_…`.
